# Credit Risk Scoring Tool

This is a simple Python script that simulates credit risk scoring based on borrower data, including:
- PAR30 and PAR60 buckets
- EMI bounce counts

### Features:
- Calculates custom risk score
- Categorizes borrower into Low, Medium, High risk
- Can be extended into a larger credit decision engine

### Technologies:
- Python
- Pandas
